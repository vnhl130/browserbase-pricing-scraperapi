## 月费之外的实际成本

Browserbase 的标价低估了实际支出的原因很简单：严重依赖代理或高并发的项目，最终支付的超额费用很容易超过订阅费本身。

浏览器时间的超额部分：超出套餐额度后，Developer 套餐需为每小时的浏览器时间支付 $0.12，Startup 套餐为 $0.10。按官方指导计算，100 浏览器小时大约相当于 3,000 个页面级任务，因为典型的抓取运行时间少于 2 分钟。因此，一个每月用满 100 小时额度后再超支 100 小时的 Developer 用户，将额外支付 $12（即 $100 × $0.12），使该月总额达到 $32。这还算可控。真正让账单增加的是代理流量：超出包含的流量后，每 GB 的成本为 $12 或 $10，具体取决于你的套餐。

Search API 的超额费用则取决于你使用的引擎。Browserbase 将 Search API 的超额价格细分为 Parallel Fast 每次 1,000 次查询 $1、Parallel Advanced 为 $5，以及 Exa 为 $7。Fetch API 调用基础价格为 $1/1,000 次，开启 Proxies 或 Extract 后为 $4，两者同时开启则为 $7。Search 和 Fetch 都有速率限制：每个项目每秒分别执行 2 次搜索和 5 次 Fetch。

模型层 (Model Gateway，即 LLM token 层) 在付费套餐中按市场价即用即付；Free 套餐包含 $5 的 token 额度以供入门。

值得了解的限制：

- **Free 套餐严格用于评估。** 1 浏览器小时，单次会话 15 分钟，7 天数据留存，没有验证码解决功能，没有 Stealth Mode。它足以回答“这个能跑通我的流程吗？”，但不足以支撑任何持续性运行。
- **付费套餐的数据留存期为 30 天** (Scale 为 30 天以上)，这意味着你可以在事后重放和调试会话。
- **公开定价页面没有年付或承诺折扣。** 你看到的是月度价格，就按月度支付。

## Browserbase 何时值得购买

当你构建的软件需要像人一样*浏览*网络时，它是物有所值的：登录应用、填写表单、多步导航、处理网站改版。它旨在与 Playwright、Puppeteer 和 Selenium 配合使用，因此现有的自动化代码无需重写即可指向托管浏览器，此外你还可以获得实时视图监控、会话回放以及面向反爬虫网站的隐身模式。

Scale 套餐增加了合规层级——HIPAA (BAA)、DPA 和 SSO——这对于有受监管数据处理需求的企业团队来说是一个真正的差异化优势。同样需要注意的是：Browserbase 提供的是基础设施。你仍需自行提供自动化逻辑和 LLM，如果你的目标网站进行了改版，无论基础设施有多好，你的流程都会中断。

## ScraperAPI 额度实际是如何消耗的

额度并不等同于请求次数，大多数定价指南在说明这一点时都含糊其辞，而这正是预算出错的地方。

根据目标不同，每次请求有不同的固定成本：普通页面消耗 **1 额度**，亚马逊为 **5 额度**，谷歌或必应搜索结果（包括其子域名）为 **25 额度**，领英 (LinkedIn) 为 **30 额度**。当服务需要绕过 Cloudflare、Datadome 或 PerimeterX 等机器人防护时，会额外增加 10 额度。

可选功能也会增加成本，且叠加方式不直观：

- `render=true`、`premium=true` 和 `screenshot=true` 每个增加 +10 额度
- `ultra_premium=true` 增加 +30 额度
- `premium` + `render` 合计为 **+25**，而非 +20
- `ultra_premium` + `render` 合计为 **+75**

这意味着每次抓取的成本差异巨大，具体取决于你的目标。每月 100,000 额度意味着可以抓取 100,000 次普通页面、20,000 次亚马逊产品页面、4,000 次谷歌查询——或者在使用超高级代理进行 JavaScript 渲染时，仅能抓取约 1,333 次受 Cloudflare 保护的页面。在做出任何承诺之前，请针对你的实际目标进行计算；仪表盘包含一个领域成本估算器 (Domain Cost Estimator)，可以在消耗你的套餐之前告诉你任意 URL 的确切成本，你还可以设置每次抓取的 `max_cost` 上限，以确保任何单个请求不会超出限制。

两点软性的优势：任何非 200 或 404 响应的失败请求都不会消耗额度，且未使用的额度不会结转——它们会在每个月重置。

## 当你达到限制时会发生什么

两个平台处理超额的方式截然不同，这应该会影响你的选择。

Browserbase 从不强制终止。你可以无限制地超过包含的额度，只需支付该套餐的超额费率。对于拥有不稳定智能体工作负载且无法承担半夜任务中断的团队来说，这是一个更友好的模式。

ScraperAPI 的默认行为更为保守：当你的额度耗尽时，抓取会暂停，直到下个周期。你有两种选择。**自动升级 (Auto-upgrade)**（可选择加入，在 Hobby 至 Professional 套餐中可用）会在你达到上限时自动将你转移到下一个套餐。**即用即付 (Pay-as-you-go)** 允许你在固定的每额度费率下继续使用，最高可设定月度支出上限——但仅在 Scaling、Professional、Advanced 和 Enterprise 套餐中可用。如果你选择的是 Hobby、Startup 或 Business，超出额度意味着你需要升级或等待重置。超过套餐的线程数会返回 429 错误，而不是排队等待。

实话实说：ScraperAPI 的即用即付设置是一个很容易被忽略的细节，如果流量激增，这会让人感到意外。如果你预计流量会激增，请在 Business 套餐中选择自动升级，或者计划购买 Scaling 套餐。
